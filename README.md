# ai-orchestra-web

**AI Orchestra** — a local-first workspace for several AI CLIs. This repository is the site: the download page and the long-form documentation.

**https://hero-999-dev.github.io/ai-orchestra-web/**

## What is here

`index.html` is the download page for Orchestra 0.1.0 and Test Orchestra 0.1.0. `handover.html` is AI Orchestra Web, the self-contained documentation. Open either file in a browser; the same pages are what GitHub Pages serves.

The application source lives in the private `ai-orchestra` repository. No project markdown is published here.
